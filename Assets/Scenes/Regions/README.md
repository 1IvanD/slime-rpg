# Regions placeholder scenes

This folder contains placeholder Unity scenes for the main regions referenced by the WorldMap generator.

How to use:
1. Open Unity and run Tools → Tempest → Create Placeholder Region Scenes (Regions).
2. The script will create Scenes under Assets/Scenes/Regions/*.unity and add them to Build Settings.
3. Replace the placeholder GameObjects (Ground, PlayerSpawn, NPCs) with your real prefabs and content.
